Visual Plan Helper

보고서용 data_sources/visual_plan.csv 초안을 안전하게 만드는 로컬 보조 도구입니다. 이 페이지는 시각자료 품질을 판단하지 않습니다. 어떤 시각자료가 필요한지는 PRD, 챕터 작업팩, 본문 주장, 독자 의사결정 기준으로 AI와 사람이 결정해야 합니다.

사용 원칙

  • 표·차트·다이어그램은 개수 채우기가 아니라 독자의 판단을 돕기 위해 만듭니다.
  • 최종 시각자료는 본문 챕터가 안정된 뒤, 해당 챕터 주장에 맞춰 확정합니다.
  • 정량 시각자료는 별도 CSV/XLSX가 필요하고, 정성 다이어그램은 source-record-backed artifact가 필요합니다.
  • 다운로드한 CSV를 프로젝트의 data_sources/visual_plan.csv로 저장한 뒤 AI에게 검토와 실제 데이터 파일 작성을 요청하세요.
