# Question Log Template

Use this log whenever the work requires user confirmation, preference, scope clarification, factual correction, or decision alignment.

| question_id | project | asked_at_kst | asked_by | question | why_asked | options_or_context | answered_at_kst | answer_summary | answer_verbatim | decision_impact | affected_files | status |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  | Codex |  |  |  |  |  |  |  |  | open / answered / superseded |

## Rules

- Ask only questions that affect scope, correctness, risk, format, or decision quality.
- Record why the question was asked.
- Record the user's answer faithfully.
- If later evidence changes the interpretation of an answer, add a new row rather than overwriting the old answer.
- Link affected files when the answer changes report scope, design, assumptions, or methodology.
