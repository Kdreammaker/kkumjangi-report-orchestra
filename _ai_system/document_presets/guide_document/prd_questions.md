# Guide Document PRD Questions

- What kind of guide is this: operating guide, producer bible, style guide, rulebook, onboarding guide, reference guide, or another guide type?
- Who is allowed to use it, and who must not see it? Record any producer-only, internal-only, locked, or approval-only sections.
- Is this a new guide or a format adaptation of existing material? If adapting, what must be preserved nearly verbatim?
- What is the target output: Word-import HTML, native DOCX, PDF, Markdown, or another file type?
- Which guide hierarchy should be used by default: `guide_outline`, `formal_outline`, `procedure_steps`, or `symbol_bullets`?
- Which sections are authoritative rules, which are examples, and which are optional interpretation notes?
- What metadata is needed: title, version, owner, source files, approval status, confidentiality, update date, and change history?
- What tables, checklists, callouts, locked notices, glossary entries, or appendix sections are required?
