# Equity Research Stage Overlays

## Workflow Mode And Stage Depth

- Default mode: `substantial`, with specialized research and non-advisory boundaries.
- Use the full evidence-backed sequence when the artifact contains sector/company analysis, valuation assumptions, financial tables, catalysts, or risk conclusions.
- Compress only when the PRD explicitly asks for a short research note; even then keep basis date, source dates, assumptions, risk, disclaimer, style pass, versioning, and review boundaries.
- Do not generate rating, target price, or buy/sell/hold language unless the user has explicitly authorized that regulated advisory context and the required approval boundary is recorded.
- If the analysis is derived from another artifact, reconfirm source dates, market data, financials, peer set, valuation assumptions, and distribution boundary before reusing conclusions.

## TOC

- Include investment context, sector dynamics, company or peer analysis, earnings/performance, valuation assumptions, catalysts, risks, and limitations.
- Keep data analysis, analyst judgment, assumptions, and disclaimers in distinct sections.

## Workpack

- Require source dates for prices, financials, consensus data, filings, and market statistics.
- Make valuation methods and assumptions explicit before presenting conclusions.
- Avoid imperative buy/sell/hold advice unless the user has explicitly authorized a regulated advisory context.
- If a Korean tone pass is requested, route it to the common style workflow and selected style profile; keep this preset focused on structure, evidence, financial data, visuals, and non-advisory boundaries.

## Visual/Data

- Prefer peer tables, earnings bridges, margin trends, valuation multiples, sensitivity tables, risk/catalyst matrices, and timeline views.
- Label stale or unaudited data clearly.

## Layout/Export

- Use a research-note hierarchy with data 기준일, disclaimer box, financial tables, peer table, sensitivity table, catalysts, risks, and limitations.
- Keep wide financial and peer tables within Word page width by splitting columns, shortening headers, or using multiple focused tables.
- Prefer static charts with captions, source dates, and alternative descriptions; avoid interactive HTML, viewport-dependent layouts, and complex absolute positioning.
- Make long issuer names, metric labels, assumptions, and URLs wrap cleanly in table cells.
- DOCX/PDF conversion requires separate export validation; this preset does not certify conversion readiness by itself.
