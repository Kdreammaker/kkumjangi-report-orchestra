# Product PRD Stage Overlays

## TOC

- Include problem, users, goals, scope, requirements, acceptance criteria, dependencies, rollout, metrics, risks, and open questions.
- Keep product decisions separate from implementation speculation.

## Workpack

- Require user story, acceptance criteria, dependency, risk, metric, and decision-log links where relevant.
- Mark any requirement that depends on unavailable data or stakeholder approval.

## Visual/Data

- Prefer user flows, state diagrams, dependency maps, release timelines, and metric trees.
- Visuals should clarify product behavior or rollout choices, not decorate the PRD.
