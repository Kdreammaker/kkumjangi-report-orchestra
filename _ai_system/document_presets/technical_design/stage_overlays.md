# Technical Design Stage Overlays

## TOC

- Include current state, target state, architecture, interfaces, data model, security, testing, operations, risks, and decisions.
- Keep implementation choices separate from open options.

## Workpack

- Require assumptions, dependencies, integration boundaries, failure modes, and testability notes.
- Mark any security or compliance claim that needs specialist validation.

## Visual/Data

- Prefer architecture diagrams, sequence flows, data models, threat/risk matrices, and rollout timelines.
- Avoid diagrams that cannot be tied to a described component or interface.
