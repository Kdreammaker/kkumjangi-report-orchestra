# Book Manuscript PRD Questions

- What kind of book is this: novel, short-story collection, nonfiction, professional book, textbook, workbook, essay collection, or another manuscript type?
- Is the task new drafting, restructuring, format cleanup, Word-import HTML, native DOCX export, or publication-prep review?
- What must be preserved: original prose, dialogue, headings, chapter order, terminology, footnotes, citations, examples, exercises, or tables?
- What is the target reader, market, age band, genre, and publication context?
- Which manuscript parts are required: front matter, parts, chapters, scenes/sections, notes, references, glossary, appendices, acknowledgments, author bio, or workbook materials?
- Which list preset should be used when hierarchy is needed: `formal_outline`, `symbol_bullets`, `guide_outline`, or `procedure_steps`?
- What editorial changes are allowed: formatting only, light consistency cleanup, structure repair, copyedit, line edit, substantive rewrite, or new material?
- What export target and verification are required: Word-import HTML, native DOCX, PDF proof, Markdown, or another file type?
