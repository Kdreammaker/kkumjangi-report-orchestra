# Book Manuscript Stage Overlays

## Workflow Mode And Stage Depth

- Default mode: `substantial` for full manuscripts, `standard` for short excerpts or format-only cleanup.
- Use PRD, manuscript inventory, structure map, part/chapter outline, source/provenance preservation, section workpacks, style/voice review, export validation, and versioning.
- Replace report chapters with book parts, chapters, scenes, sections, lessons, exercises, notes, references, glossary, and appendices.
- For novels and literary works, preserve voice, dialogue, pacing, scene boundaries, names, and canon unless the user explicitly authorizes rewrite.
- For nonfiction/professional books, preserve claims, citations, examples, tables, and definitions, and distinguish evidence from author interpretation.

## TOC

- Organize by front matter, body matter, back matter, and appendices.
- Use `formal_outline` for formal/professional hierarchy and book outlines when nested structure is needed.
- Use `symbol_bullets` for examples, options, notes, exercises, and compact supporting material.
- Avoid forcing report-style executive summaries, recommendations, or Chapter 0 unless the book brief asks for them.

## Workpack

- Each part/chapter workpack should track purpose, reader function, source/provenance, protected spans, allowed editorial depth, and continuity/citation concerns.
- Fiction workpacks should track point of view, timeline, character/canon constraints, scene purpose, and continuity risks.
- Nonfiction/professional workpacks should track thesis, evidence, examples, tables/figures, citations, caveats, and reader takeaways.
- Formatting-only requests should not become rewriting tasks.

## Visual/Data

- Prefer tables, figures, sidebars, exercises, worksheets, glossary tables, and citation/reference blocks only when they serve the book type.
- For manuscripts intended for Word import, keep figures static and captions inline-first.
- For workbook/textbook style content, keep answer spaces, exercises, and checklists simple enough for Word/PDF review.

## Layout/Export

- Use manuscript-safe structure: title page/metadata, front matter, parts, chapters, sections/scenes, notes/references, appendices, and revision log when needed.
- Keep styling conservative and inline-first for HTML import: headings, paragraphs, lists, captions, callouts, tables, and sidebars.
- Do not claim final publishing layout, print-ready imposition, ebook packaging, automatic index, running heads, or cross-reference automation unless separately implemented and verified.
- Native DOCX export should preserve part/chapter hierarchy and selected list presets, but export validation remains required.
