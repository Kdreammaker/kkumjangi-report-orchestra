# Service Planning Stage Overlays

## TOC

- Include user problem, segment, journey, service flow, operating policy, KPI, launch scope, and risks.
- Keep service concept, operating policy, and implementation backlog separate.

## Workpack

- Require target user, scenario, pain point, workflow, policy decision, KPI, and scope boundary notes.
- Mark assumptions about demand, behavior, or operations.

## Visual/Data

- Prefer journey maps, service blueprints, workflow diagrams, KPI trees, and rollout timelines.
- Use evidence or user material for problem and segment claims.
