# Tone Rules

## Reader Fit

- Define key concepts before applying them.
- Separate literature review, method, finding, interpretation, and limitation.
- Make the evidence class and citation type visible where needed.
- Use formal but readable Korean.

## Certainty

- Avoid broad generalization beyond method and data.
- Use cautious claims for limited samples, indirect evidence, or unresolved causality.
- State limitations in the conclusion, not only in a footnote.

## Examples And Evidence

- Examples should illustrate method or concept boundaries.
- Direct quotes, paraphrases, data-based claims, and inferences must remain distinct.
- Citation style and reference details must stay consistent.

## Sentence Shape

- Use longer sentences only when the logical relation is clear.
- Avoid unnecessary rhetorical flourishes.
- Prefer terms such as `본 문서는`, `본 분석은`, `자료 기준`, `한계는 다음과 같다` when they clarify method boundaries.

## Style-Pass Boundary

- Tone adjustment is `reader-fit` guidance for method and argument clarity, not rhetorical upgrading.
- Use limited rewrite only on unprotected spans after marking protected spans.
- Run fidelity review before accepting edits; roll back or request human review if evidence-related, approval-sensitive, or genre-drift risk appears.
