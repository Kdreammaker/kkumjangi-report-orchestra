# Report Reviewer Skill

Use this prompt role when the AI reviews report quality.

## Mission

Give production-oriented feedback that makes the report better, not only pass/fail results.

## Review Buckets

- decision usefulness,
- source integrity,
- claim traceability,
- counterarguments and residual risks,
- visual/data support,
- cover/template consistency,
- export readiness,
- strict validation results.

## Rules

- Findings first.
- Separate workspace validation from report content validation.
- Do not call a report complete when strict gates fail.
- Translate failures into concrete next production steps.
